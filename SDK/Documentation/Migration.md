# Migration to 0.1.0-rc.1

This release introduces separate compiled Apple SDK packages. Keep native macOS and iOS module names and implementations separate. Select the platform's extracted binary package and its named product. The macOS CLI and iOS demonstration app remain source development consumers; neither ships in an SDK runtime ZIP.

Provide explicit source-bearing semantic mappings, known-valid facts, intent constraints, real referenced diagnostic chains, registered policies and native resource ownership. Historical context-free healing constructors remain available where compatible, but invocation without the required context now fails before I/O. Arbitrary JSON structural drift is not a substitute for ASH projection or correction proof. Update caller composition rather than suppressing this failure.

Request policy files deliberately. Missing, malformed or violated provided policy fails closed, including no-action paths. Mandatory audit is independent of optional diagnostics. Choose fresh backup destinations: existing backups are never overwritten. A failed or unverified restore no longer reports successful rollback. Terminal containment/halt requires application-owned lifecycle handling.

Canonical JSON and pointer semantics replace lossy dotted-key and Boolean/number comparisons in healing paths. Review any caller that relied on conflating null/missing, flattening arrays or silently accepting unavailable evidence. Use the frozen `AeostaraContract` DTOs for the baseline interface rather than historical CLI-shaped result JSON.

Public release diagnostics are bounded, lean and optional. Rich diagnostic components are development-only. Do not link the internal development target into production, invent SDK provenance in consumer metadata, or place sensitive payloads in telemetry. Export into a private caller-owned directory and handle structured partial failures.
