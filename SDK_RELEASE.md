# Aeostara Apple SDK 0.1.0-rc.1 release record

The two final native SDK binary packages and their admitted external consumers passed technical acceptance. [SDK_RELEASE.json](SDK_RELEASE.json) records exact native commits, source tags, product closure, four prepared asset hashes, reviewed evidence and qualification limits. The final external release manifest additionally records the coordination commit and is hashed into SHA256SUMS after this commit exists. Tag and GitHub publication receipts are separate from this immutable preparation record.

Install the compiled SDK ZIPs from the [coordinated prerelease](https://github.com/flynn33/Aeostara-Mac-iOS/releases/tag/sdk/apple/v0.1.0-rc.1) once published. GitHub's automatically generated repository-source archives are not SDK binaries. Follow the extracted platform Integration.md, separate guide and consumer-owned examples, then verify every asset against SHA256SUMS.

Both native implementations preserve the frozen base/ASH pins and public schema while correcting reproduced canonical integer, plan-integrity, explicit-context, audit/recovery, resource-lifecycle and diagnostic failures. Services requires application-owned mappings, policy, intent, scope and lifecycle; optional lean diagnostics do not replace mandatory durable audit. Rich development collectors are excluded from runtime frameworks.

The owner dual license is reproduced exactly; commercial use requires a separate written license. The release is a candidate, not a stable or physical-hardware-qualified product. See the [tested matrix](PLATFORM_STATUS_MATRIX.md) and precise limits in the release record and guide. Historical source changelogs and migration receipts retain their original version/identity rather than being relabeled SDK acceptance.
