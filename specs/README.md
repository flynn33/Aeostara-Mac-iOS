# Legacy native API references

The retained contract schemas, interface descriptions and acceptance documents describe the existing native API compatibility surface and historical test scenarios. They do not define ASH semantics or certify the complete pinned Aeostara lifecycle.

Use [the native baseline and authority record](../Docs/NATIVE_BASELINE.md) and [the immutable upstream baseline reference](../AEOSTARA_BASELINE_REFERENCE.md) for current authority. The obsolete generic-healing algorithm and architecture corpus was retired with its original content preserved in Git history. No canonical specification corpus is shipped as SDK runtime material.
